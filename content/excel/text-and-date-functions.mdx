## What it is

Text functions split, clean and combine strings. Date functions create and manipulate date serial numbers.

## Why it exists

Exports frequently contain codes with embedded meaning, stray spaces and dates in odd formats.

## How it works

`TRIM` removes extra spaces, leaving single spaces between words. Non-breaking spaces from web pages aren't removed, so use `SUBSTITUTE(A1,CHAR(160)," ")` first. `TEXT` converts a value to formatted text, which means the result can no longer be used in math or date calculations.

## Syntax and key APIs

```text
=LEFT("INV-2026-77",3)             INV
=RIGHT("INV-2026-77",2)            77
=MID("INV-2026-77",5,4)            2026
=TRIM("  a   b ")                  a b
=SUBSTITUTE("a-b-c","-","/")       a/b/c
=TEXT(E2,"yyyy-mm")                2026-01
=DATE(2026,3,15)
=EOMONTH(DATE(2026,2,10),0)        28 February 2026
=TEXTBEFORE("a@b.com","@")         a
=TEXTAFTER("a@b.com","@")          b.com
```

## Simple example

To convert a text date like `15/03/2026` when Excel doesn't parse it, build it from parts:

```text
=DATE(RIGHT(A2,4),MID(A2,4,2),LEFT(A2,2))
```

## Industry examples

Finance teams use `EOMONTH` to create month-end calendars. Data operations teams parse SKU codes into category and region columns.

## Patterns and best practices

- Clean repeating feeds with Power Query instead of formula columns.
- Keep real dates in cells, and use number formats for display.
- Use ISO-like `yyyy-mm` text when you need a sortable month key.

## Alternatives and trade-offs

Flash Fill quickly extracts patterns, though it doesn't update. Power Query's Split Column is repeatable and handles delimiters well.

## Common mistakes

- Using `TEXT` for a date and then trying to sort it chronologically with day-first formats.
- Assuming `TRIM` removes non-breaking spaces.
- Dates interpreted differently under a different locale.
- `TEXT` format codes that vary by language settings.
