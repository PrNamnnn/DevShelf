## What it is

Bivariate analysis studies how two variables move together or how one differs across the groups of another.

## Why it exists

Most business questions are comparisons. Does churn differ by plan? Does revenue rise with ad spend? Examining pairs is usually where hypotheses appear.

## How it works

The combination of types selects the method:

| Pair | Summary | Chart | Inference |
| --- | --- | --- | --- |
| Numeric and numeric | Covariance, Pearson, Spearman | Scatter | Correlation test, regression |
| Numeric and categorical | Group means, medians | Box, grouped bars | t-test, ANOVA, rank tests |
| Categorical and categorical | Cross-tab with percents | Stacked bars, heatmap | Chi-square |

In a cross-tab, choose the percentage base deliberately. Row percentages answer "of basic users, how many churned?", while column percentages answer "of churned users, how many were basic?".

## Worked example

Six customers produce this table:

| Plan | Stayed | Churned |
| --- | --- | --- |
| Basic | 1 | 2 |
| Pro | 2 | 1 |

Basic churn is 2 of 3 and Pro is 1 of 3. That's a large gap, but six people can't support a conclusion. The bivariate summary raises the question, and inference decides whether the data can answer it. On the same data, the correlation between age and spend is 0.89, a strong pattern that still needs a causal explanation, since older customers may simply have higher incomes.

## Python

```python
import pandas as pd

df = pd.DataFrame({
    "plan": ["basic", "basic", "pro", "pro", "pro", "basic"],
    "churned": [1, 0, 0, 0, 1, 1],
    "age": [22, 35, 41, 29, 38, 24],
    "spend": [120, 200, 340, 260, 300, 150],
})

table = pd.crosstab(df["plan"], df["churned"], normalize="index")
assert round(table.loc["basic", 1], 3) == 0.667
assert round(df["age"].corr(df["spend"]), 2) == 0.89
assert df.groupby("plan")["spend"].median().to_dict() == {"basic": 150.0, "pro": 300.0}
```

## SQL

```sql
SELECT plan,
       count(*) AS customers,
       round(avg(churned), 3) AS churn_rate
FROM (VALUES ('basic', 1), ('basic', 0), ('pro', 0), ('pro', 0), ('pro', 1), ('basic', 1))
       AS c(plan, churned)
GROUP BY plan
ORDER BY plan;
-- rows: [{"plan":"basic","customers":3,"churn_rate":"0.667"},{"plan":"pro","customers":3,"churn_rate":"0.333"}]
```

## Excel or Power BI

A Pivot Table with one field in Rows, another in Columns and "Show Values As % of Row Total" is a cross-tab. Scatter charts plus `CORREL` cover numeric pairs. In Power BI, use a matrix for cross-tabs and a scatter visual with a trend line.

## In industry

Segment comparisons fill most business reviews. Teams need to confirm that a gap between segments is more than a difference in customer mix, which is where multivariate methods take over.

## Assumptions and limitations

A pair can hide a third variable. **Simpson's paradox** occurs when a trend present in every subgroup reverses once they're combined, usually because group sizes differ across a confounder. Correlation measures only specific kinds of association.

## Common mistakes

- Using the wrong percentage base in a cross-tab.
- Concluding from a very small group.
- Summarizing nonlinear relationships with a single Pearson coefficient.
- Plotting too many overlapping points without transparency or binning.

## Alternatives

Stratify by a suspected confounder, or use multiple regression. For many variables at once, a correlation matrix or pair plot is a faster overview.
