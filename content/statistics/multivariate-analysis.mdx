## What it is

Multivariate analysis considers three or more variables simultaneously, either to explain an outcome or to find structure among the variables themselves.

## Why it exists

Real outcomes have many causes and variables overlap. Multivariate methods answer what two-variable views can't, such as whether a relationship survives once a confounder is held constant.

## How it works

| Goal | Method | Output |
| --- | --- | --- |
| Quick overview | Correlation matrix, pair plot | Which pairs to examine |
| Remove a confounder | Partial correlation, multiple regression | Adjusted relationship |
| Effect depends on another variable | Interaction term | Conditional effect |
| Reduce many columns | PCA | Uncorrelated components |
| Find latent constructs | Factor analysis | Interpretable factors |
| Group similar rows | Cluster analysis | Segments |

**PCA** rotates standardized data so the first component captures as much variance as possible, and each later one captures the most remaining variance while staying orthogonal. **Factor analysis** instead assumes hidden factors cause the observed variables, and it models shared variance only.

## Intuition and formula

<Formula>r_xy.z = (r_xy − r_xz r_yz) / √((1 − r_xz²)(1 − r_yz²))</Formula>

This is the correlation between x and y once the linear effect of z is removed from both.

## Worked example

In a simulation of 2,000 customers, x and y are both driven by z. Raw correlation between x and y is 0.47, which looks like a meaningful link. The partial correlation controlling for z is −0.02, so the relationship was entirely due to z. With five survey questions measuring two underlying attitudes, PCA's first two components explain 57% and 38% of the variance, which supports reducing five columns to two.

## Python

```python
import numpy as np
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(5)
n = 2_000
z = rng.normal(0, 1, n)
x = z + rng.normal(0, 1, n)
y = z + rng.normal(0, 1, n)
r = np.corrcoef([x, y, z])
partial = (r[0, 1] - r[0, 2] * r[1, 2]) / np.sqrt((1 - r[0, 2] ** 2) * (1 - r[1, 2] ** 2))
assert round(r[0, 1], 2) == 0.47
assert abs(partial) < 0.05

rng = np.random.default_rng(1)
f1, f2 = rng.normal(0, 1, (2, 1_000))
noise = lambda: rng.normal(0, 0.3, 1_000)
survey = np.c_[f1 + noise(), f1 + noise(), f1 + noise(), f2 + noise(), f2 + noise()]
ratios = PCA().fit(StandardScaler().fit_transform(survey)).explained_variance_ratio_
assert ratios[:2].sum() > 0.9
```

## In industry

Marketing uses clustering for segments and factor analysis for survey design. Multiple regression is the standard way to adjust comparisons. PCA compresses correlated sensor or financial series.

## Assumptions and limitations

PCA is linear and sensitive to scale, so standardize first, and components can be hard to name. Clusters always appear, even in random data, so validate that they're stable and useful. Adjustment only handles the confounders you measured.

## Common mistakes

- Running PCA without scaling.
- Treating PCA components as if they were real-world causes.
- Controlling for a variable that is a consequence of the treatment.
- Choosing a cluster count because the output looks tidy.

## Alternatives

Random forests and gradient boosting capture nonlinear interactions automatically. Decision trees give understandable segments. t-SNE and UMAP help visualize high-dimensional data, though distances between clusters on their plots shouldn't be interpreted.

## Interview questions

<Question q="What is the difference between PCA and factor analysis?">PCA summarizes total variance as combinations of variables. Factor analysis models observed variables as caused by latent factors and separates shared from unique variance.</Question>

<Question q="Why standardize before PCA?">PCA follows variance. Without scaling, the column with the largest units dominates regardless of importance.</Question>
