## What it is

**Embeddings** map discrete items to vectors in which similar meaning is nearby. **Attention** computes a weighted combination of inputs based on relevance. **Transformers** stack attention with feed-forward layers.

## Why it exists

RNNs process serially and forget distant context. Attention directly connects any two positions, and it can be parallelized.

## How it works

Each token produces a query, key and value. Dot products between queries and keys determine weights, which then mix the values. Multi-head attention runs several in parallel. Because attention has no inherent order, positional encodings are added. Decoders mask future positions during training.

Standard blocks use attention, layer normalization, residual connections and a feed-forward layer.

## Intuition and formula

<Formula>Attention(Q, K, V) = softmax(QKᵀ / √d) V</Formula>

Dividing by √d prevents large dot products from pushing softmax into very small gradients.

## Worked example

With a query aligned to the first key, attention gives the first value most of the weight. Cosine similarity between embeddings for "king" and "queen" is typically higher than with "banana" in real pretrained vectors, and the toy vectors below mimic this.

## Python

```python
import numpy as np

def attention(q, k, v):
    scores = q @ k.T / np.sqrt(k.shape[-1])
    weights = np.exp(scores) / np.exp(scores).sum(-1, keepdims=True)
    return weights @ v, weights

q = np.array([[4.0, 0.0]])
k = np.array([[4.0, 0.0], [0.0, 4.0]])
v = np.array([[1.0], [10.0]])

output, weights = attention(q, k, v)
assert weights[0, 0] > 0.99
assert round(weights.sum(), 6) == 1
assert output.item() < 1.2

cosine = lambda a, b: a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
king, queen, banana = np.array([0.9, 0.8, 0.1]), np.array([0.85, 0.82, 0.15]), np.array([0.1, 0.05, 0.95])
assert cosine(king, queen) > cosine(king, banana)
```

## In industry

Transformers are the foundation of large language models, semantic search and many multimodal systems. Pretrained embeddings power retrieval systems.

## Assumptions and limitations

Models need large training budgets and can produce confident errors. Embedding similarity reflects training data, including its biases.

## Common mistakes

- Comparing embeddings from different models.
- Forgetting attention masks.
- Training from scratch when a pretrained model would suit.
- Skipping retrieval evaluation.

## Alternatives

TF-IDF is cheap and interpretable, and smaller fine-tuned models reduce cost and latency.

## Interview questions

<Question q="Why scale by √d?">To keep dot-product variance from growing with dimension and saturating softmax.</Question>

<Question q="Why do transformers need positional encoding?">Attention itself ignores order.</Question>
