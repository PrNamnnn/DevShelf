## What it is

`open` returns a file object for reading or writing. `pathlib.Path` represents a filesystem path as an object.

## Why it exists

Most programs exchange data through files. `with` guarantees the file closes, and `Path` replaces fragile string manipulation.

## How it works

Text mode decodes bytes into `str` using an encoding, and binary mode gives raw `bytes`. Writes go through a buffer, so data may not reach the disk until the file closes.

A file object is an iterator over lines and reads lazily, so large files don't need to fit in memory.

| Mode | Meaning |
| --- | --- |
| `r` | Read (default) |
| `w` | Write, truncating first |
| `a` | Append |
| `x` | Create, fail if it exists |
| `b` | Binary |
| `t` | Text (default) |

## Syntax and key APIs

```py
from pathlib import Path

path = Path("data") / "report.txt"
path.name  path.stem  path.suffix  path.parent
path.exists()  path.is_file()  path.resolve()
path.read_text(encoding="utf-8")
path.write_text("hi", encoding="utf-8")
path.parent.mkdir(parents=True, exist_ok=True)
Path(".").glob("*.py")   Path(".").rglob("*.py")
path.unlink(missing_ok=True)   path.with_suffix(".md")
```

## Simple example

```python
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as folder:
    path = Path(folder) / "logs" / "app.txt"
    path.parent.mkdir(parents=True, exist_ok=True)

    with path.open("w", encoding="utf-8") as f:
        f.write("one\ntwo\n")

    with path.open(encoding="utf-8") as f:
        lines = [line.strip() for line in f]

    assert lines == ["one", "two"]
    assert (path.stem, path.suffix) == ("app", ".txt")
```

## Industry examples

### Write atomically

A crash during a direct write leaves a partial file. Writing to a temporary file and replacing it means readers see the old or the new content.

```python
import json, os, tempfile
from pathlib import Path

def save_json(path, data):
    fd, tmp = tempfile.mkstemp(dir=path.parent, suffix=".tmp")
    with os.fdopen(fd, "w", encoding="utf-8") as f:
        json.dump(data, f)
    os.replace(tmp, path)

with tempfile.TemporaryDirectory() as folder:
    target = Path(folder) / "state.json"
    save_json(target, {"v": 1})
    assert json.loads(target.read_text(encoding="utf-8")) == {"v": 1}
```

### Process CSV by column name

```python
import csv, io

source = io.StringIO("id,total\n1,10\n2,5\n")
rows = list(csv.DictReader(source))
assert sum(int(r["total"]) for r in rows) == 15

out = io.StringIO()
writer = csv.DictWriter(out, fieldnames=["id"], lineterminator="\n")
writer.writeheader()
writer.writerow({"id": 1})
assert out.getvalue() == "id\n1\n"
```

### Serialize custom types to JSON

```python
import json
from datetime import date

def encode(value):
    if isinstance(value, date):
        return value.isoformat()
    raise TypeError(type(value))

assert json.dumps({"d": date(2026, 1, 2)}, default=encode) == '{"d": "2026-01-02"}'
```

## Patterns and best practices

- Always pass `encoding="utf-8"` for text.
- Use `with` for every file.
- Iterate large files by line.
- Use `/` from `Path`, never string concatenation.
- Validate user-supplied paths stay within an allowed directory.

## Alternatives and trade-offs

| Need | Option | Trade-off |
| --- | --- | --- |
| Small file | `read_text` | Whole file in memory |
| Large file | Iterate lines | One pass |
| Config | `tomllib`, JSON | Read-only for tomllib |
| Tabular analytics | Parquet or pandas | Extra dependency |

## Common mistakes

**Omitting encoding.** On older Python versions the default depends on the platform.

**Using mode `w` on data you meant to keep.** It truncates immediately.

**Checking `exists()` then opening.** Another process may interfere. Use `x` mode or handle the exception.

**Reading a huge file with `read()`.** Memory grows with file size.

## Interview questions

<Question q="Why use with open(...)?">
It closes the file even if an exception occurs, and flushes buffered writes.
</Question>

<Question q="How do you read a 50 GB file?">
Iterate over the file object line by line, or read fixed-size chunks.
</Question>
