## What it is

CPython frees most objects through **reference counting**, and a cyclic garbage collector handles reference loops.

## Why it exists

You don't call free, but memory still has to be reclaimed. Counting frees objects promptly. Cycles need a separate pass because their counts never reach zero.

## How it works

Local names live in function frames, while the objects they refer to live on the heap.

## Syntax and key APIs

| Tool | Purpose |
| --- | --- |
| `sys.getrefcount(x)` | Count, plus one for the call |
| `sys.getsizeof(x)` | Shallow size in bytes |
| `gc.collect()` | Force a cycle collection |
| `weakref.ref(x)` | Refer without keeping alive |
| `tracemalloc` | Trace allocations |
| `__slots__` | Remove per-instance `__dict__` |

## Simple example

```python
import gc

class Node:
    freed = 0
    def __del__(self):
        Node.freed += 1

a, b = Node(), Node()
a.other, b.other = b, a
del a, b

assert Node.freed == 0
gc.collect()
assert Node.freed == 2
```

## Industry examples

### Cache without keeping objects alive

```python
import gc, weakref

class Image:
    pass

cache = weakref.WeakValueDictionary()
image = Image()
cache["logo"] = image
assert cache["logo"] is image

del image
gc.collect()
assert "logo" not in cache
```

### Find what is allocating

```python
import tracemalloc

tracemalloc.start()
data = [str(i) for i in range(10000)]
current, peak = tracemalloc.get_traced_memory()
tracemalloc.stop()

assert current > 100_000
assert peak >= current
```

### Shrink many small objects

```python
import sys

class Plain:
    def __init__(self):
        self.x = 1

class Slotted:
    __slots__ = ("x",)
    def __init__(self):
        self.x = 1

assert hasattr(Plain(), "__dict__")
assert not hasattr(Slotted(), "__dict__")
```

## Patterns and best practices

- Use `with` for external resources rather than relying on collection.
- Use generators to keep large data out of memory.
- Keep long-lived caches bounded.
- Measure with `tracemalloc` before optimizing.

## Alternatives and trade-offs

| Technique | Helps | Cost |
| --- | --- | --- |
| `__slots__` | Many instances | No dynamic attributes |
| Generators | Large data | One pass |
| `weakref` | Caches | Entries can vanish |
| `array`, NumPy | Numeric data | One type |

## Common mistakes

**Relying on `__del__` for cleanup.** Timing isn't guaranteed. Use context managers.

**Unbounded global dictionaries.** That's the most common Python leak.

**Trusting `sys.getsizeof` for containers.** It doesn't include the objects they refer to.

**Assuming `del` frees memory.** It removes one reference.
