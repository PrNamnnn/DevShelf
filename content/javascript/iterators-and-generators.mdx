## What it is

An iterable has a `[Symbol.iterator]` method returning an iterator, whose `next()` gives `{ value, done }`. A generator function, `function*`, creates iterators that can pause at `yield`.

## Why it exists

One protocol powers `for...of`, spread and destructuring for arrays, Maps, Sets and your own types. Generators produce values on demand.

## How it works

Calling a generator runs nothing. Each `next()` resumes until the next `yield`.

## Syntax and key APIs

```javascript
function* gen() { const received = yield 1; yield* other(); return 2; }
const [a, b] = gen();
for await (const chunk of stream) {}
async function* pages() { yield await fetchPage(); }
values().filter(isOk).map(transform).take(5).toArray();
```

## Simple example

```js
import assert from "node:assert";

class Range {
  constructor(from, to) {
    Object.assign(this, { from, to });
  }
  *[Symbol.iterator]() {
    for (let n = this.from; n <= this.to; n++) yield n;
  }
}

assert.deepEqual([...new Range(1, 3)], [1, 2, 3]);
const [first] = new Range(5, 9);
assert.equal(first, 5);
```

## Industry examples

### Hide pagination

```js
import assert from "node:assert";

async function* allItems(fetchPage) {
  for (let page = 1; ; page++) {
    const items = await fetchPage(page);
    if (items.length === 0) return;
    yield* items;
  }
}

const data = { 1: ["a", "b"], 2: ["c"] };
const seen = [];
for await (const item of allItems(async (p) => data[p] ?? [])) seen.push(item);

assert.deepEqual(seen, ["a", "b", "c"]);
```

### Lazy transformation

Iterator helpers only do the work that's demanded.

```js
import assert from "node:assert";

let produced = 0;
function* naturals() {
  for (let n = 1; ; n++) {
    produced++;
    yield n;
  }
}

const result = naturals().filter((n) => n % 2 === 0).take(2).toArray();
assert.deepEqual(result, [2, 4]);
assert.equal(produced, 4);
```

### Clean up with return

Leaving a `for...of` early calls the iterator's `return`, running `finally`.

```js
import assert from "node:assert";

let closed = false;
function* source() {
  try {
    yield 1;
    yield 2;
  } finally {
    closed = true;
  }
}

for (const value of source()) break;
assert.equal(closed, true);
```

## Patterns and best practices

- Implement `[Symbol.iterator]` on collection classes.
- Use generators for sequences that could be large or infinite.
- Use `for await` for streams and paginated APIs.
- Check iterator helper support in the browsers you target.

## Alternatives and trade-offs

| Need | Option | Trade-off |
| --- | --- | --- |
| Small data | Arrays | Eager and allocated |
| Large or infinite | Generators | Single use |
| Events over time | Observables or streams | More concepts |

## Common mistakes

**Reusing a generator.** It's exhausted after one pass.

**Spreading an infinite generator.** It never ends.

**Using `for...of` on a plain object.** Objects aren't iterable. Use `Object.entries`.

**Awaiting one by one when work could overlap.** Sequential awaits can be slow.

## Interview questions

<Question q="What makes an object iterable?">
A `[Symbol.iterator]` method that returns an object with a `next()` method.
</Question>

<Question q="What does yield do?">
It pauses the generator and passes a value out. The next `next()` call resumes from there.
</Question>
