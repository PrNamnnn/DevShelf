## What it is

Streaming returns output incrementally. Async methods such as `ainvoke` let many model calls overlap on one thread.

## Why it exists

Model calls are slow. Seeing the first words quickly transforms perceived speed, and async avoids blocking a server while waiting.

## How it works

For agents, a stream mode selects what you receive.

| Mode | Yields |
| --- | --- |
| `updates` | State after each agent step |
| `messages` | `(token, metadata)` from the model |
| `custom` | Data from `get_stream_writer` |

For new applications, the docs recommend `stream_events(..., version="v3")`.

## Syntax and key APIs

```py
for chunk in model.stream("Hi"): ...
async for chunk in model.astream("Hi"): ...
await model.ainvoke("Hi")
for token, metadata in agent.stream(inputs, stream_mode="messages"): ...
```

## Simple example

```python
import asyncio
from langchain.messages import AIMessage
from langchain_core.language_models.fake_chat_models import GenericFakeChatModel

async def main():
    model = GenericFakeChatModel(messages=iter([AIMessage(content="one two")]))
    return [chunk.content async for chunk in model.astream("Hi")]

chunks = asyncio.run(main())
assert "".join(chunks) == "one two"
assert len(chunks) > 1
```

## Industry examples

### Bounded concurrency

```python
import asyncio
from langchain_core.language_models.fake_chat_models import FakeListChatModel

async def summarize(model, limit, text):
    async with limit:
        return (await model.ainvoke(text)).content

async def main():
    model = FakeListChatModel(responses=["ok"])
    limit = asyncio.Semaphore(2)
    return await asyncio.gather(*(summarize(model, limit, t) for t in ["a", "b", "c"]))

assert asyncio.run(main()) == ["ok", "ok", "ok"]
```

### Stream agent steps

```python
from langchain.agents import create_agent
from langchain.messages import AIMessage
from langchain_core.language_models.fake_chat_models import GenericFakeChatModel

class Scripted(GenericFakeChatModel):
    def bind_tools(self, tools, **kwargs):
        return self

agent = create_agent(Scripted(messages=iter([AIMessage(content="done")])), tools=[])

steps = list(agent.stream({"messages": [{"role": "user", "content": "go"}]}, stream_mode="updates"))
assert "model" in steps[0]
```

### Server-sent events

```py
from fastapi.responses import StreamingResponse

async def events(prompt):
    async for chunk in model.astream(prompt):
        yield f"data: {chunk.text}\n\n"

@app.post("/chat")
async def chat(prompt: str):
    return StreamingResponse(events(prompt), media_type="text/event-stream")
```

## Patterns and best practices

- Stream user-facing output.
- Set timeouts, and handle client disconnects.
- Limit concurrency to stay inside rate limits.
- Don't parse partial JSON unless your parser supports it.

## Alternatives and trade-offs

| Need | Option | Trade-off |
| --- | --- | --- |
| Interactive chat | `stream` | More client code |
| Background job | `invoke` | Slower perceived |
| Bulk processing | `batch` | No partial output |

## Common mistakes

**Calling blocking `invoke` in an async route.** It blocks the event loop.

**Not cancelling on disconnect.** You keep paying for tokens no one reads.

**Assuming tokens align with words.** Chunks can split anywhere.

**Using `get_stream_writer` outside graph execution.** It only works inside it.

## Interview questions

<Question q="Why stream model output?">
